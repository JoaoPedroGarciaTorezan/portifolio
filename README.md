# Portfólio

Site de portfólio pessoal com apresentação, projetos, serviços e formas de contato.

## Sobre o projeto

Este projeto contém um site desenvolvido para a capacitação da byron solutions.

## Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, Grid e Media Queries)
- Font Awesome (ícones)
- Google Fonts (Poppins)

## Funcionalidades

- Layout responsivo (mobile e desktop)
- Seções: Home, Sobre, Projetos, Serviços, Conhecimentos e Contato
- Links para redes sociais e repositórios
